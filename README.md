# BallisticCalculator — Qt 5.11.1 / C++14

Настольное приложение для расчёта траектории трёхступенчатой ракеты-носителя. Интерфейс использует Qt Widgets; вычислительное ядро `BallisticCore` — отдельная статическая библиотека C++14 без зависимости от Qt.

## Структура проекта

```text
BallisticCalculator.pro     Общий проект qmake для Qt Creator
build-release.cmd          Сборка и подготовка dist/Release
rebuild-release.cmd        Полная пересборка и подготовка dist/Release
src/
  app/                      Точка входа и проект приложения
  core/                     Численная модель и библиотека BallisticCore
  ui/                       Окна, фоновый расчёт и графики QPainter
tests/
  core/                     Тесты численного ядра
  ui/                       Тесты интерфейса
docs/                       Руководство пользователя и API ядра
scripts/                    Сборка, проверка и упаковка для Windows
LICENSES/                   Сохранённые уведомления об авторских правах
artifacts/                  Промежуточные сборки и журналы, исключены из Git
dist/Release/               Приложение и библиотеки для запуска, исключены из Git
```

## Сборка и запуск

Проверенное окружение: **Qt 5.11.1 MSVC2017 64bit**, MSVC 2017 и Windows x64. Из корня репозитория:

```powershell
.\build-release.cmd
```

Для полной пересборки с удалением промежуточных файлов выполнить `rebuild-release.cmd`. Оба скрипта можно запускать из любого рабочего каталога; они находят проект по своему расположению.

Скрипты собирают Release, запускают тесты ядра и интерфейса, заново создают `dist/Release`, добавляют Qt DLL и MSVC runtime, проверяют расчёт и отрисовку из этой папки и создают ZIP. `dist/Release` — генерируемый каталог, его содержимое заменяется при сборке. Пути к инструментам можно переопределить переменными `QT_DIR`, `VCVARS64`, `VC_REDIST_DIR`; значения по умолчанию приведены в [руководстве](docs/user-guide.ru.md). Общая реализация находится в `scripts/build-qt.cmd`.

Готовое приложение:

```text
dist/Release/BallisticCalculator.exe
```

Для переноса на другой Windows 10/11 x64 ПК использовать **всю папку** `dist/Release` или архив `dist/BallisticCalculator-Qt5.11.1-win64.zip`. Qt и Visual Studio на целевом ПК не требуются. Рядом с EXE размещаются Qt Core/Gui/Widgets/Svg, MSVC runtime, графические библиотеки, плагины `platforms`, `styles`, `imageformats`, `iconengines` и `qt.conf` для поиска локальных плагинов. В поставке находится также `BallisticCalculator-native-source.zip` с соответствующими исходниками и скриптами сборки; перед сборкой его нужно распаковать.

В **Qt Creator** открыть корневой `BallisticCalculator.pro`, выбрать комплект **Desktop Qt 5.11.1 MSVC2017 64bit** и отдельный каталог сборки, например `artifacts/qt-creator`. Запускаемая цель — `BallisticCalculator`. Общий проект сначала собирает ядро, затем приложение и тесты; все потребители линкуются с одной библиотекой.

## Возможности

- Семь графиков на пяти вкладках: скорость, высота, угол атаки, программа, перегрузка, дальность и профиль высоты.
- Масштабирование, панорамирование, просмотр координат и маркеры событий ступеней.
- Расчёт с заданной программой или подбор двух параметров по высоте и скорости.
- Фоновое выполнение, отмена и корректное закрытие во время расчёта.
- Проверка входных данных; ввод чисел с точкой или запятой.
- Автоматическая светлая/тёмная тема Windows, включая открытые диалоги и графики.
- Поля с подсветкой ошибок, сводка масс и клавиши Ctrl+Enter / Esc для расчёта и остановки.

## Документация и проверки

[Руководство пользователя и физическая модель](docs/user-guide.ru.md) · [Сборка и API ядра](docs/core-api.ru.md) · [Анализ интерфейса и тем](docs/ui-design.ru.md).

В версии **2.1.0** исправлены ввод через Ctrl+Enter и граничные режимы подбора,
введена проверка всей программы угла, ускорены большие графики. Подробнее:
[численная проверка](docs/numerical-validation.ru.md),
[поставка и откат](docs/release-validation.ru.md),
[выполненные этапы рефакторинга](docs/refactoring-validation.ru.md).
Поставка включает `build-manifest.json` с версиями и SHA-256. Предыдущая рабочая
версия сохраняется в `dist/previous-*`; замена выполняется после всех проверок.

Тесты ядра проверяют RK4, атмосферу, события ступеней, валидацию, воспроизводимость, сходимость и отмену. Тесты интерфейса проверяют ввод, диалоги, фоновое выполнение и графики. Журналы штатной сборки:

```text
artifacts/qt-release/native/tests/core/core-tests.txt
artifacts/qt-release/native/tests/ui/ui-tests.txt
```
