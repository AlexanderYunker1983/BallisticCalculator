# BallisticCalculator — баллистический калькулятор ракет‑носителей (WPF)

## Описание

**BallisticCalculator.Wpf** — это WPF‑приложение на C# / .NET для моделирования и оптимизации траектории полёта трёхступенчатой ракеты‑носителя.  
Численное ядро реализовано в наборе классов в папке `CalculationCore` внутри проекта, интерфейс реализован по паттерну MVVM (через `CommunityToolkit.Mvvm`), визуализация графиков — с помощью `OxyPlot.Wpf`.

---

## Основные возможности

- **Моделирование полёта трёхступенчатой ракеты‑носителя**
- **Численное интегрирование уравнений движения методом Рунге–Кутты 4‑го порядка** с адаптивным шагом по скорости
- **Автоматическая оптимизация программы полёта**:
  - подбор угла поворота `Φ₁` для достижения целевой высоты орбиты (≈ 250 км);
  - подбор времени поворота `Φ₁Time` для достижения целевой орбитальной скорости на этой высоте.
- **Учёт атмосферы** (плотность, давление, температура, скорость звука) по модели стандартной атмосферы
- **Учёт аэродинамических сил** с зависимостью коэффициентов от числа Маха
- **Наглядные графики (OxyPlot)**:
  - скорость
  - высота
  - угол атаки
  - программа полёта
  - перегрузка
  - ортодромная дальность
  - профиль высоты (высота как функция ортодромной дальности)
- **Автоматические маркеры разделения ступеней** на всех временных графиках

## Структура решения

- **`BallisticCalculator.Wpf`** — WPF‑клиент и вычислительное ядро
  - `App.xaml` / `App.xaml.cs` — точка входа, общие ресурсы приложения (DPI‑friendly стили для окон и текста).
  - `MainWindow.xaml` / `MainWindow.xaml.cs` — главное окно, установка `DataContext` в экземпляр `MainWindowViewModel`.
  - `InitialParamsWindow.xaml` / `InitialParamsWindow.xaml.cs` — диалог редактирования начальных параметров ракеты.
  - `ViewModels/MainWindowViewModel.cs` — основная view‑model, содержит:
    - редактируемые свойства параметров ракеты и программы полёта (через `[ObservableProperty]`);
    - асинхронную команду `RunCommand` / `RunCommandCancel` для запуска и отмены расчёта;
    - модели графиков `PlotModel` для всех отображаемых величин.
- **Папка `CalculationCore` в `BallisticCalculator.Wpf`** — вычислительное ядро (пространство имён `CalculationCore`)
  - `CalculationCore.cs` — управляющий класс численного расчёта и оптимизации (`RunAsync`, внутренний метод `RunCore`).
  - `CalculationResult.cs` — результат расчёта (траектория + оптимальные `Phi1Time` и `Phi1Degrees`).
  - `CalculationVector.cs` — состояние ракеты (радиус, скорость, угол, масса и т.п.) и функции перехода на новый шаг.
  - `InitialParams.cs` — структура всех исходных параметров ракеты и времён работы ступеней.
  - `AtmosphereInterpolator.cs` / `AtmosphereParams.cs` — модель стандартной атмосферы с интерполяцией параметров по высоте.

## Интерфейс и сценарий работы

### Главное окно (`MainWindow`)

Главное окно привязано к `MainWindowViewModel` и включает:

- **Кнопку запуска расчёта** (команда `RunCommand`);
- Отображение итоговых параметров:
  - `VelocityInfo` — пара «фактическая скорость → требуемая орбитальная»;
  - `AltitudeInfo` — высота орбиты в километрах;
- Набор графиков (по `PlotModel`):
  - скорость `V(t)`
  - высота `H(t)`
  - угол атаки `α(t)`
  - программа полёта `φ(t)`
  - перегрузка `n(t)` в единицах g
  - ортодромная дальность `S(t)`
  - профиль высоты `H(S)`

На всех временных графиках автоматически отображаются **вертикальные красные линии** в моменты разделения ступеней (`Time1`, `TimeSumm2`, `TimeSumm3`).

### Окно начальных параметров (`InitialParamsWindow`)

Отдельное диалоговое окно позволяет редактировать параметры ракеты:

- **Массы:**
  - полезной нагрузки (`MassGo`);
  - 1‑й, 2‑й и 3‑й ступеней (`Mass1`, `Mass2`, `Mass3`);
- **Массы топлива:** `MassFuel1`, `MassFuel2`, `MassFuel3`;
- **Тяга ступеней:** `Thrust1`, `Thrust2`, `Thrust3`;
- **Удельный импульс:** `Isp1`, `Isp2`, `Isp3`.

Все поля связаны через `Binding` с `MainWindowViewModel` и обновляются по мере ввода (`UpdateSourceTrigger=PropertyChanged`).

### Параметры программы полёта

В главном окне редактируются:

- `Phi0Time` — длительность начального участка (сек);
- `Phi1Time` — время поворота программы полёта (строковое поле, парсится с учётом текущей культуры);
- `Phi1Degrees` — угол поворота в градусах (также строковое поле).

При запуске расчёта:

1. Введённые значения `Phi1Time` и `Phi1Degrees` конвертируются в double.
2. Формируется структура `InitialParams`.
3. Вызывается `_calculationCore.SetInitParams(...)` и асинхронный расчёт `_calculationCore.RunAsync(...)`.
4. После завершения расчёта через `Dispatcher` обновляются графики и итоговые значения.

## Математическое ядро и оптимизация

### Алгоритм оптимизации

В `CalculationCore.CalculationCore` реализован двухуровневый поиск:

1. **Внутренний цикл по углу `Phi1`**  
   Подбирает угол поворота программы полёта так, чтобы итоговая высота траектории была близка к 250 км.

2. **Внешний цикл по времени `Phi1Time`**  
   Подбирает момент поворота так, чтобы итоговая скорость соответствовала орбитальной скорости на высоте 250 км.

После сходимости сохраняются:

- оптимальное значение `Phi1Time`;
- соответствующий ему угол `Phi1` (в радианах и градусах).

### Численное интегрирование

- Используется **метод Рунге–Кутты 4‑го порядка**;
- Шаг интегрирования **адаптивный**:
  - базовый шаг `dt` уменьшается или увеличивается в зависимости от текущей скорости;
  - дополнительно шаг корректируется так, чтобы не «перепрыгивать» моменты разделения ступеней — расчётные точки совпадают с `Time1`, `TimeSumm2`, `TimeSumm3`.
- В каждой точке учитываются:
  - тяга активной ступени и текущая масса (расход топлива);
  - гравитация (закон обратных квадратов);
  - аэродинамическое сопротивление (коэффициенты зависят от числа Маха);
  - параметры атмосферы из `AtmosphereInterpolator`;
  - программа поворота траектории.

Результат возвращается в `CalculationResult`:

- список точек траектории (`Trajectory: List<CalculationVector>`);
- найденные оптимальные `Phi1Time` и `Phi1Degrees`.

## Атмосфера и аэродинамика

- `AtmosphereInterpolator` и `AtmosphereParams` реализуют модель стандартной атмосферы для высот от 0 до 300 км:
  - плотность воздуха;
  - давление;
  - температура;
  - скорость звука.
- В `CalculationVector` вычисляются:
  - коэффициент лобового сопротивления `Cx`;
  - коэффициент подъёмной силы `Cy`;
  как функции числа Маха.

## Особенности реализации

- **MVVM‑архитектура:** логика UI сосредоточена во view‑model (`MainWindowViewModel`), окна отвечают только за представление.
- **CommunityToolkit.Mvvm:** используется генерация свойств (`ObservableObject`, `[ObservableProperty]`) и команд (`[RelayCommand]`).
- **Асинхронные расчёты:** тяжёлые вычисления выполняются в пуле потоков, UI не блокируется; есть встроенная команда отмены.
- **DPI‑корректный интерфейс:** в `App.xaml` заданы стили для окон и текста (layout rounding, SnapsToDevicePixels и режимы рендеринга текста).
- **Единообразный стиль графиков OxyPlot:** оси и сетка настраиваются через общий вспомогательный метод.
